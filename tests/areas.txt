# The areas of the tests that run by area before merging
# (docs/architecture/build.md, Test triggers): each such target and the
# source paths it covers. A diff that touches one of a target's paths
# triggers it (`bazel run //tools/xtask -- suites`).
#
# Format, one entry per line:
# - `//package:target` at the start of a line begins a target's paths;
# - `@set` at the start of a line begins a named set of paths;
# - an indented line is a path of the entry above: a glob relative to the
#   repository's root (`*` matches within one path segment, `**` any number
#   of segments, `{a,b}` is not supported), or `@set` to include a set;
# - `#` begins a comment line; blank lines are ignored.
# Every set is defined before it is used.
